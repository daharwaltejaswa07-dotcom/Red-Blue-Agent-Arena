💡 Why CYBER-02 Matters to Enterprises

  • OWASP #1 Threat for 2026: Prompt Injection is the single biggest threat as companies give agents email, files, and bank tools.
  • The Flaw of Chatbots: Traditional LLM guardrails only filter user text. They fail when prompt injection is hidden in PDF invoices, emails, or websites the agent browses.
  • Our Solution: A Semantic Guardian Proxy that sits between the agent and its tools to measure intent divergence.

🏆 How We Hit Every Frontier Hackathon Criteria

  • 3 Realistic Tools: Integrated Email, Browser/PDF Files, and Mock Payment tool.
  • Autonomous Red Team: Picks and mutates attacks from a learned strategy, so bypasses differ on every run.
  • Semantic Defense (Not Keyword Filter): Evaluates intent divergence between stated goal and tool arguments.
  • Both Agents Improve: Blue Guardian patches itself after every real bypass and every false positive.
  • Usefulness Preserved: Utility is measured on real legitimate tasks each round, including false-positive bait and owner-approval cases.
